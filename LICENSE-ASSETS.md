# Third-party assets

V1zir Visuals bundles the following fonts. Their license texts ship inside the jar at
`assets/v1zir/fonts/licenses/`.

| File(s) | Font | License |
|---|---|---|
| `inter_*.ttf` | Inter, © The Inter Project Authors | SIL Open Font License 1.1 |
| `montserrat_*.ttf` | Montserrat, © The Montserrat Project Authors | SIL Open Font License 1.1 |
| `rubik_*.ttf` | Rubik, © The Rubik Project Authors | SIL Open Font License 1.1 |
| `nunito_*.ttf` | Nunito, © The Nunito Project Authors | SIL Open Font License 1.1 |
| `comfortaa.ttf` | Comfortaa, © The Comfortaa Project Authors (unmodified) | SIL Open Font License 1.1 |
| `lucide.ttf` | Lucide icons, © Lucide Icons and Contributors | ISC License |

The Inter, Montserrat, Rubik and Nunito files are static instances generated from the official
variable fonts in [google/fonts](https://github.com/google/fonts) and subset to Latin,
Latin Extended-A and Cyrillic. Comfortaa is shipped unmodified because its license reserves
the font name. The Lucide font is subset to the icons used by the mod.
